# ADR 018 — Server grading, retry credit and guest migration

The owner explicitly accepts M8's current Gallia/atlas experience and authorizes M9 on 2026-10-23, retaining outstanding historical, specialist-art, listening and real-device checks without marking them passed. The PRD defines five questions, four options, immediate source-backed feedback, difficulty-scaled XP and thematic ranks, but omits reward amounts and thresholds. The owner approves 10/20/30 XP for difficulties 1/2/3 and rank thresholds 0/50/150/350/700/1200/2000. These amounts and thresholds share `lib/quiz/progression.ts`. Gallia offers at most 90 XP, so it cannot unlock every rank; thresholds are provisional and must be reassessed as the catalog grows.

Grade only on the server against a private question snapshot stored with each quiz session. Public responses explicitly allowlist ID, prompt and options; reveal a verdict, explanation, selected-option feedback and sources only after that question's validated submission. Strict JSON contracts, canonical-origin checks, account/opaque guest-cookie ownership, sequential answering and unique session/question answers reject malformed, mismatched, foreign and conflicting submissions. Same-choice retries are idempotent. XP is banked only on completion of all five questions, once per account/question for its first correct answer. A profile lock followed by a session lock, one transaction and the unique user/question credit ledger prevent duplicate or concurrent awards. Fresh retries can earn previously missed questions and otherwise remain practice. Deleting an attempt does not delete its earned credit.

Local storage holds untrusted attempt references and viewed-beat IDs, never authoritative XP, rank, score or dates. Anonymous attempts are graded and stored on the server, bound to a random HttpOnly/SameSite guest cookie whose hash is stored in the database. Signup or login's profile view imports only completed, server-owned attempts from the same browser, regrades their stored answers and deduplicates credit transactionally. References alone cannot transfer rewards. Viewed-beat imports are self-reported convenience progress with no XP or streak award. A newly claimed completed attempt counts as activity today; imported dates never backdate a streak. Completed quizzes, including practice, count once per server UTC calendar day; adjacent days extend the streak, a missed day resets it, and every relevant UI shows “Daily streak resets at 00:00 UTC”. There is no quiz deadline: an owned unfinished session can resume after a long reading break. Browser/session credentials still require the same owner. Local migrations/seed/testing use an isolated database; applying or seeding shared Neon requires separate owner approval.
